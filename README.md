# FitTrack - Fitness Tracker

FitTrack is a web application designed to help users track
their fitness activities, meals, water intake, and progress.

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- FlightPHP
- MySQL

## Project Structure

- frontend/ - User interface and Bootstrap template
- backend/ - REST API and database operations
- docs/ - Project documentation

## Features (Planned)

- User registration and login
- Fitness dashboard
- Exercise tracking
- Meal tracking
- Hydration tracking
- Progress tracking
- Admin and user roles

## Development

The project is currently in Milestone 1.
